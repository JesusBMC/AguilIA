# Requirements Document

> **MVP-Deploy Spec** — Generated by ArchMagnet.
> This spec covers the minimum viable functionality: business logic + infra + deploy.
> For the complete solution use the **Full Spec** (sibling directory under `specs/`).

## Introduction
Minimum requirements to build and deploy the MVP solution on AWS.
Every requirement carries **two layers of acceptance criteria**:
  1. Functional intent from the PRFAQ → Kiro generates implementation tasks.
  2. CloudFormation provisioning → Kiro generates cfn-validate + cfn-deploy tasks.
The starting IaC is in `iac/template.yaml` (validated by ArchMagnet).

## Glossary
- **RDEP**: requirements of this deploy spec.
- **IaC**: Infrastructure as Code (`iac/template.yaml` bundled in this Power).
- **CFN**: AWS CloudFormation.

### Requirement 17: Validate the CloudFormation template before the deploy (RDEP01)
**User Story:** As a DevOps engineer, I want to validate the template before the deploy,
so that syntax and deployability errors surface early.
#### Acceptance Criteria
1. WHEN a deploy is requested THEN THE SYSTEM SHALL validate the CloudFormation template
   at `iac/template.yaml` using the AWS CLI before creating any AWS resources.
2. WHEN the template is invalid THEN THE SYSTEM SHALL surface the cfn-lint errors and
   halt the deploy.

### Requirement 18: Deploy the CloudFormation stack to AWS (RDEP02)
**User Story:** As a DevOps engineer, I want to deploy the stack to AWS in minutes.
#### Acceptance Criteria
1. WHEN the template is valid THEN THE SYSTEM SHALL deploy the CloudFormation stack
   `agilia-cf608d` to AWS using `iac/template.yaml` with CAPABILITY_NAMED_IAM.
2. WHEN the deploy completes THEN THE SYSTEM SHALL verify the stack status is
   `CREATE_COMPLETE` or `UPDATE_COMPLETE` and report the deployed resource ARNs.
3. WHEN the deploy fails THEN THE SYSTEM SHALL surface the CloudFormation stack events
   and the root cause of the failure.

### Requirement 19: Continue with the Full Spec for the complete solution (RDEP03)
**User Story:** As a developer, once the MVP is working, I want to continue with the
Full Spec to build the complete solution.
#### Acceptance Criteria
1. WHEN the CloudFormation stack is CREATE_COMPLETE THEN THE SYSTEM SHALL guide the
   developer to copy `specs/<slug>/requirements.md` to `.kiro/specs/<slug>/` and generate
   design and tasks from the Full Spec requirements using Kiro.
